# Gen-AI Cohort Notes

This repository contains my learning notes, practice files, and small projects from the Gen-AI cohort. The topics are organized class by class so it is easy to track what I learned in each session.

## Class-by-Class Learning

| Class | What I Learned |
| --- | --- |
| Class 01 | How LLMs work, transformers, tokens, and the core ideas behind generative AI. |
| Class 02 | Prompting techniques such as zero-shot, few-shot, chain-of-thought, tool use, and role play prompts. Also includes a small weather app exercise. |
| Class 03 | Using AI SDKs in code, including OpenAI, Claude, and Gemini examples, plus streaming responses and interview practice files. |
| Class 04 | Docker basics, container setup, and RAG-related practice files for working with retrieval workflows. |
| Class 05 | Project 1, Part 1: ChatGPT clone project placeholder. The full project will live in the ChaiGPT repository. |
| Class 06 | Project 1, Part 2: continuation of the ChatGPT clone project. The full project will live in the ChaiGPT repository. |
| Class 07 | Advanced RAG patterns, including query rewriting, query ranking, and HyDE. |
| Class 08 | Reserved for future cohort work or additional exercises. |
