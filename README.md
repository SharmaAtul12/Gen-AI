# Gen-AI Cohort

This repository contains my learning notes, exercises, and small Gen-AI projects completed during the cohort. The content is organized by class and mostly uses JavaScript and Node.js examples with API-based AI integrations.

## Current Repository Status

- The repository now includes completed work for Classes 01 through 10.
- Most folders contain runnable Node.js examples with their own dependencies.
- Class 08 is the most complete project-style example, featuring document processing and retrieval workflows.
- Class 09 is now marked as completed and includes the final cohort materials and notes.
- Class 10 is now marked as completed and includes TypeScript-based agent and app examples.

### Expanded Details

- Class 01: Covers how LLMs work at a basic level, including token handling and the first scripts in the cohort.
- Class 02: Focuses on prompting patterns and includes a small weather app exercise.
- Class 03: Shows how to use AI SDKs in Node.js, including streaming output and interview practice files.
- Class 04: Introduces Docker and a simple RAG workflow for indexing and querying content.
- Class 05: Marks the first part of Project 1 and acts as a milestone placeholder.
- Class 06: Marks the second part of Project 1 and continues the project milestone structure.
- Class 07: Explores advanced RAG patterns such as query rewriting, ranking, and HyDE.
- Class 08: Contains the most complete project-style example with ingestion, queueing, workers, and Qdrant/OpenAI integration.
- Class 09: Wraps up the cohort with final notes and follow-up exercises.
- Class 10: Covers the Agent SDK, TypeScript app structure, and related configuration examples.

## Getting Started

1. Open the class folder you want to explore.
2. Install dependencies with npm install if a package.json file is present.
3. Review the environment file and add any required API keys.
4. Run the relevant script from that folder.

## Notes

- This repository is primarily a learning workspace rather than a production-ready application.
- The structure is intentionally class-based so it is easy to track progress across the course.
